# Backend Differences

```@meta
CurrentModule = PowerGraphics
```

Every `plot_*` function takes a `backend` key word: [`CairoMakieBackend`](@ref)`()` (the
default, static figures) or [`PlotlyLightBackend`](@ref)`()` (interactive HTML). The two
backends are not pixel-identical. This page lists what is the same on both and what
differs.

## Identical on both backends

| Behavior                   | Behavior on both backends                                                                                                                                                                                                                        |
|:-------------------------- |:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Series draw order          | On non-bar plots, series whose values sum to a negative total (storage charging, source input) are drawn first, then the rest, each group keeping its column order.                                                                              |
| Sign-aware stacking        | A series is classified by the sign of its total, not per time step. Positive series stack upward from 0 and negative series stack downward from 0. A positive series that is 0 at a time step (PV at night) stays in place as a zero-width band. |
| `nofill` default           | `nofill = !bar && !stack`: a plain line plot has no area fill; stacked and bar plots do.                                                                                                                                                         |
| `linestyle` / `linewidth`  | `linestyle::Symbol` defaults to `:solid`; `linewidth` defaults to `1`.                                                                                                                                                                           |
| Title                      | No title by default; a single-space `" "` title is treated as no title.                                                                                                                                                                          |
| Untitled save filename     | A [`plot_dataframe`](@ref) save with no title is written to `dataframe.<format>`.                                                                                                                                                                |
| Empty `DataFrame`          | Warns `"Plot dataframe empty: skipping plot creation"` and returns the plot unchanged, without labels, legend or file.                                                                                                                           |
| Series colors              | Both backends use the same colors from the palette given by [`load_palette`](@ref), continuing the color cycle past series already on the plot.                                                                                                  |
| Legend labels (`label_fn`) | `label_fn` defaults to [`label_short`](@ref) and produces the same legend text on both backends.                                                                                                                                                 |
| Reserve stacks             | [`plot_fuel`](@ref) with `service` draws the same fuel categories, values and colors on both backends.                                                                                                                                           |

## Differences between backends

| Behavior                  | CairoMakie                                                                                                | PlotlyLight                                                                                                                                       | Reason                                                                                                                           |
|:------------------------- |:--------------------------------------------------------------------------------------------------------- |:------------------------------------------------------------------------------------------------------------------------------------------------- |:-------------------------------------------------------------------------------------------------------------------------------- |
| Save formats              | `png` (default), `pdf`, `svg`. A `.html` filename throws an `ArgumentError`.                              | `html` only. Any other extension warns and is rewritten to `.html`; the rewritten path is returned.                                               | PlotlyLight has no image export; CairoMakie has no HTML output. An explicit `format` key word overrides the default.             |
| Time axis                 | Ticks only at the first and last timestamps.                                                              | Native date-time axis with automatic ticks.                                                                                                       | CairoMakie's stacked-area primitive cannot use a `DateTime` axis, so CairoMakie plots use a numeric axis with labeled endpoints. |
| Bar-plot x-axis           | Grouped bars (`stack = false`) get one rotated tick label per category; stacked bars have no tick labels. | No tick labels on bar plots.                                                                                                                      | Bars are identified by the legend; rotated labels keep long CairoMakie category names readable.                                  |
| Y-axis range              | Fitted to the data; zero is not forced into range.                                                        | Always includes zero.                                                                                                                             | Plotly's zero-anchored range has no exact CairoMakie equivalent.                                                                 |
| Stacked-area band outline | Not drawn on non-stair stacked plots (drawn with `stair = true`).                                         | Always drawn.                                                                                                                                     | A CairoMakie outline on intermittent series draws vertical streaks across the stack.                                             |
| `save_plot` key words     | Ignored.                                                                                                  | `autoplay`, `post_script`, `full_html`, `animation_opts`, `default_width` and `default_height` are passed to the HTML writer; others are ignored. | These are PlotlyLight HTML options with no CairoMakie equivalent.                                                                |
| Figure size               | Fixed at `1280 × 720`.                                                                                    | Plotly's responsive default.                                                                                                                      | Neither backend accepts a `size` key word.                                                                                       |
